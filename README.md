# Mass Tort Marketing Agency - Web Application Landing Page

A high-converting, modern, and futuristic web application landing page engineered specifically for **Mass Tort Marketing Agency**.

---

## 🌟 Key Features & Architecture

### 1. Hero Section & 3D Interactive Particle Matrix
- **Headline**: *"Scale Your Law Firm with AI-Driven Mass Tort Campaigns"*
- **Canvas Particle Engine**: Vanilla HTML5 Canvas rendering interactive 3D particle nodes that represent claimants and litigation data points, reacting dynamically to cursor movements and mouse proximity.
- **Dynamic Accent CTA**: *"Launch Your Campaign"* styled with radiant glowing accents and micro-interactions.
- **Floating Visual Data Cards**:
  - **Cost Per Retainer Card**: Showcases live average cost ($680/signed retainer vs. $2,400 industry standard with a 71.2% cost reduction indicator).
  - **Conversion Rate Card**: Showcases 38.4% click-to-signed retainer conversion metrics with real-time intake telemetry.

### 2. Interactive Lead Qualification Funnel (Mockup)
- **Glassmorphism UX**: Ultra-modern frosted glass styling (`backdrop-filter: blur(16px)`), dynamic border glows, and step progression bar.
- **Multi-Step Claimant Qualification**:
  - **Step 1: Docket Selection**: Camp Lejeune PACT Act, Commercial Truck & MVA, Ozempic/GLP-1 Gastroparesis, and Zantac NDMA.
  - **Step 2: Medical & Exposure Screening**: Diagnosis criteria, hospitalization records check, and existing attorney representation verification.
  - **Step 3: Contact & TCPA Verification**: Simulated phone OTP and carrier verification.
  - **Step 4: Live Retainer Dispatch & CRM Sync**: Claimant qualification score (98.5/100 Tier-1 Retainer), estimated case settlement bracket ($250k - $1.2M), and live JSON webhook payload delivery preview.

### 3. Services Showcase
Minimalist 3-column grid layout with hover micro-interactions, ambient light blooms, and animated elevation:
- **High-Intent Ad Campaigns**: Precision search intent capture, algorithmic MDL targeting, and negative keyword filtering.
- **Custom Landing Pages**: Sub-500ms load speeds, 38.4% conversion rate legal funnels, and HIPAA-compliant architecture.
- **Backend Automated Funnels**: Sub-28 second speed-to-lead automated calls, conversational SMS intake, and DocuSign integration.

### 4. Interactive Financial Modeling & Docket ROI Calculator
- Law firm partners can adjust the **Monthly Ad Budget Allocation** ($10k - $250k) and choose target litigation dockets to immediately calculate:
  - Estimated signed retainers per month.
  - Target Cost Per Retainer.
  - Projected gross docket recovery value.

### 5. CRM Integrations Section
Crisp vector badges showcasing seamless zero-friction API synchronization with:
- **Salesforce**
- **HubSpot**
- **Clio Manage**
- **Lead Docket**
- **Filevine**
- **DocuSign**

### 6. Floating WhatsApp Booking & Quick Consultation
- Sticky floating WhatsApp action button with unread counter ping.
- Interactive modal with a pre-formatted inquiry message directly linkable to `https://wa.me/...`.

### 7. Dynamic Brand Palette & Theme Engine
- Includes an interactive **Palette & Theme Controller** in the top navigation allowing instant toggling between:
  - ⚖️ **Royal Blue & Gold** (Default brand identity)
  - ⚡ **Cyber Cyan & Amber**
  - 🏛️ **Legal Emerald & Brass**
  - 🔥 **Crimson Tort & Electric Cyan**
  - ☀️ **Clean Corporate Light Theme** / 🌙 **Obsidian Dark Theme**

## 🚀 How to Run

Simply open `index.html` in any modern web browser:
```bash
# In PowerShell:
Start-Process "index.html"
```
Or start a local development server:
```bash
# Using Python:
python -m http.server 3000

# Or using npx:
npx serve .
```
Open `http://localhost:3000` in your browser.
